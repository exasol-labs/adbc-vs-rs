## Summary
- Axes checked: 6/6

## How this plan may fail

1. A MySQL query that groups by a newly mapped `BIT(1)`, `TIME`, `YEAR`, or `JSON` column and projects a predicate over that key fails at MySQL with error 1055. The key now renders as a read expression, and MySQL matches a grouped expression only whole. Routed to Requirement Quality, `[REQUIREMENT_CONFLICT]` BLOCKER.
2. The Script Language Container cuts a microsecond timestamp to milliseconds. The task 2.7 contingency keeps `TIMESTAMP(6)`, so the type-mapping scenario stays red and a delegated timestamp equality disagrees with the emitted value. Routed to Feasibility, `[UNSTATED_ASSUMPTION]` BLOCKER.
3. The user reads "`bit` maps to `BOOLEAN`" and finds it delivered for width 1 only, on a rationale that decision [6] invalidates. Routed to Intent Fidelity, `[INTENT_DRIFT]` BLOCKER.

Add a scenario "A select-list predicate over a grouped converted column is delegated" to the `vs-adapter/mysql-type-mapping` delta, whose rows must equal the mirror's. Add a unit test in `mysql_dialect_tests.rs`, and E2E queries `SELECT NOT BIT_FLAG, COUNT(*) ... GROUP BY BIT_FLAG` and `SELECT Y = DATE '2024-01-01', COUNT(*) ... GROUP BY Y` in task 3.6.
